本节适用于 V2。使用 API Key 调用接口，并为分析任务和地址监控选择对应的接入流程。

## 开始接入

1. 完成[快速开始](/zh/quickstart)，运行一次分析任务。
2. 阅读[分析任务接入](/zh/guides/v2/analysis)，处理状态变化与结果读取。
3. 阅读[地址监控接入](/zh/guides/v2/monitoring)，接收事件并管理监控地址。

## 参数范围

V2 分析任务与添加监控地址接口支持 `chain` 为 `ethereum`、`bsc`、`tron`，`token` 为 `usdt`。字段详情以对应接口页面为准。

维护已有 V1 集成时，查看 [V1 版本概览](/zh/guides/v1/overview)。不同版本的请求路径和事件结构应分别查阅。
