## 连接文档 MCP

在已发布的 Arisk 文档页面中，打开页面上下文菜单并选择 **MCP**，复制文档服务器地址。将它添加到支持远程 HTTP MCP 的 AI 工具中。

文档 MCP 地址是文档站根地址加上 `/mcp`。使用菜单中提供的地址，保留站点可能包含的路径前缀。

连接后，让 AI 搜索并读取相关接口页面，再生成集成代码。例如：

```text
请读取 Arisk 简体中文 V2 文档，说明如何创建分析任务、查询状态并获取结果。
请核对请求必填字段、任务状态和响应结构，并附上文档链接。
```

此连接用于搜索和读取文档。执行地址分析或修改监控配置需要单独调用 Arisk API，并使用您的 API Key。

## 提供 Markdown 内容

如果您的工具不支持 MCP，可使用页面菜单复制 Markdown，或在页面 URL 后添加 `.md` 获取 Markdown 内容。

文档站根路径下的 `llms.txt` 提供页面索引，`llms-full.txt` 提供文档内容。自动生成的索引默认面向站点默认语言和版本；需要其他语言或 V1 时，请同时提供对应页面链接。

## 生成代码前核对

- 明确指定 API 版本与文档语言，避免混用 V1 和 V2 路径。
- 核对请求域名为 `https://api.arisk.io`，认证请求头为 `X-API-Key`。
- 用占位符代替真实 API Key，在您自己的运行环境中设置密钥。
- 将生成的字段和枚举值与接口参考对照。

从[快速开始（V2）](/zh/quickstart)完成首次接入，或查看[创建分析任务](/zh/api-reference/v2/endpoint/analysistaskcreate)的完整参数。
