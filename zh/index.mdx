Arisk 帮助您识别链上风险资金，通过地址分析、资金流向查询和监控告警，为 AML 风控业务提供数据支持。

<Card title="快速开始（V2）" icon="rocket" href="/zh/quickstart">
  使用 API Key 创建分析任务、查询状态并获取结果。
</Card>

## 链与代币参数

V2 分析任务支持的 `chain` 值为 `ethereum`、`bsc`、`tron`，`token` 值为 `usdt`。请求时使用这些小写标识。
