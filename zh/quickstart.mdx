本指南使用 V2。维护 V1 集成时，请在版本选择器中切换到 V1，并使用对应的接口参考。

## 1. 准备 API Key

准备已在 Arisk 控制台创建的 API Key，并在终端设置环境变量。需要帮助时，联系 [Arisk 支持](https://t.me/arisk_cs)。

```bash
export ARISK_API_KEY="YOUR_API_KEY"
export ARISK_API_BASE="https://api.arisk.io"
```

<Note>
在服务端使用 API Key，不要将它放入公开仓库、前端代码或发送给 AI 工具。
</Note>

## 2. 创建分析任务

下面的请求分析一个 Ethereum 地址的 USDT 活动。`chain`、`token` 和 `address` 必填；可将 `address` 替换为您需要分析的地址。

```bash
curl --fail-with-body --request POST "$ARISK_API_BASE/v2/analysis/tasks" \
  --header "X-API-Key: $ARISK_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "chain": "ethereum",
    "token": "usdt",
    "address": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    "metrics": ["overview", "risk_type", "risk_address_total"]
  }'
```

成功响应包含 `task_id`。将实际返回的值保存到环境变量，后续请求使用同一个任务 ID。

```bash
export ARISK_TASK_ID="TASK_ID_FROM_RESPONSE"
```

## 3. 查询任务状态

```bash
curl --fail-with-body "$ARISK_API_BASE/v2/analysis/tasks/$ARISK_TASK_ID/status" \
  --header "X-API-Key: $ARISK_API_KEY"
```

根据 `status` 决定下一步。等待中或处理中时，稍后再次查询；失败时检查 `message` 并停止等待。

| 值 | 状态 |
| --- | --- |
| `0` | 等待中 |
| `1` | 处理中 |
| `2` | 已完成 |
| `3` | 失败 |

## 4. 获取分析结果

当 `status` 为 `2` 时获取结果。响应的 `result` 对象包含分析数据；完整字段请查看[获取分析结果接口](/zh/api-reference/v2/endpoint/analysistaskresultget)。

```bash
curl --fail-with-body "$ARISK_API_BASE/v2/analysis/tasks/$ARISK_TASK_ID/result" \
  --header "X-API-Key: $ARISK_API_KEY"
```

## 选择分析指标

`metrics` 为可选字段，不传或传入空数组时返回全部支持的指标。示例只请求 `overview`、`risk_type` 和 `risk_address_total`。更多指标和筛选参数见[创建分析任务](/zh/api-reference/v2/endpoint/analysistaskcreate)。

## 处理错误

请求报错时查看响应中的 `code` 和 `message`，结合[通用错误码](/zh/api-reference/common-errors)和[分析错误码](/zh/api-reference/analysis-errors)定位原因。任务失败与 HTTP 请求失败需要分别处理。
