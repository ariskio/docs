本節適用於 V2。使用 API Key 呼叫介面，並為分析任務和地址監控選擇對應的接入流程。

## 開始接入

1. 完成[快速開始](/zh-Hant/quickstart)，執行一次分析任務。
2. 閱讀[分析任務接入](/zh-Hant/guides/v2/analysis)，處理狀態變化與結果讀取。
3. 閱讀[地址監控接入](/zh-Hant/guides/v2/monitoring)，接收事件並管理監控地址。

## 參數範圍

V2 分析任務與添加監控地址介面支援 `chain` 為 `ethereum`、`bsc`、`tron`，`token` 為 `usdt`。欄位詳情以對應介面頁面為準。

維護已有 V1 整合時，查看 [V1 版本概覽](/zh-Hant/guides/v1/overview)。不同版本的請求路徑和事件結構應分別查閱。
