Arisk 協助您識別鏈上風險資金，透過地址分析、資金流向查詢和監控告警，為 AML 風控業務提供資料支援。

<Card title="快速開始（V2）" icon="rocket" href="/zh-Hant/quickstart">
  使用 API Key 建立分析任務、查詢狀態並取得結果。
</Card>

## 依任務開始

<Columns cols={2}>
<Card title="建立分析任務" icon="magnifying-glass" href="/zh-Hant/api-reference/v2/endpoint/analysistaskcreate">
  提交地址，選擇需要的分析指標。
</Card>
<Card title="查看分析結果" icon="chart-line" href="/zh-Hant/api-reference/v2/endpoint/analysistaskresultget">
  讀取地址概覽、風險類型統計和資金流向。
</Card>
<Card title="新增監控地址" icon="shield-check" href="/zh-Hant/api-reference/v2/endpoint/monitoraddressesadd">
  批次新增需要持續監控的地址。
</Card>
<Card title="查詢監控告警" icon="bell" href="/zh-Hant/api-reference/v2/endpoint/monitoralertslist">
  取得監控地址的告警記錄。
</Card>
</Columns>

## 鏈與代幣參數

V2 分析任務支援的 `chain` 值為 `ethereum`、`bsc`、`tron`，`token` 值為 `usdt`。請求時使用這些小寫識別值。

本指南使用 V2。維護 V1 整合時，請在版本選擇器中切換至 V1，並使用對應的介面參考。
