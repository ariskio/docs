本指南使用 V2。維護 V1 整合時，請在版本選擇器中切換至 V1，並使用對應的介面參考。

## 1. 準備 API Key

準備已在 Arisk 控制台建立的 API Key，並在終端設定環境變數。需要協助時，聯絡 [Arisk 支援](https://t.me/arisk_cs)。

```bash
export ARISK_API_KEY="YOUR_API_KEY"
export ARISK_API_BASE="https://api.arisk.io"
```

<Note>
在伺服器端使用 API Key，不要將它放入公開儲存庫、前端程式碼或傳送給 AI 工具。
</Note>

## 2. 建立分析任務

以下請求分析一個 Ethereum 地址的 USDT 活動。`chain`、`token` 和 `address` 為必填；可將 `address` 替換為您需要分析的地址。

```bash
curl --fail-with-body --request POST "$ARISK_API_BASE/v2/analysis/tasks" \
  --header "X-API-Key: $ARISK_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "chain": "ethereum",
    "token": "usdt",
    "address": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    "metrics": ["overview", "risk_type", "risk_address_total"]
  }'
```

成功回應包含 `task_id`。將實際回傳的值儲存至環境變數，後續請求使用同一個任務 ID。

```bash
export ARISK_TASK_ID="TASK_ID_FROM_RESPONSE"
```

## 3. 查詢任務狀態

```bash
curl --fail-with-body "$ARISK_API_BASE/v2/analysis/tasks/$ARISK_TASK_ID/status" \
  --header "X-API-Key: $ARISK_API_KEY"
```

根據 `status` 決定下一步。等待中或處理中時，稍後再次查詢；失敗時檢查 `message` 並停止等待。

| 值 | 狀態 |
| --- | --- |
| `0` | 等待中 |
| `1` | 處理中 |
| `2` | 已完成 |
| `3` | 失敗 |

## 4. 取得分析結果

當 `status` 為 `2` 時取得結果。回應的 `result` 物件包含分析資料；完整欄位請查看[取得分析結果介面](/zh-Hant/api-reference/v2/endpoint/analysistaskresultget)。

```bash
curl --fail-with-body "$ARISK_API_BASE/v2/analysis/tasks/$ARISK_TASK_ID/result" \
  --header "X-API-Key: $ARISK_API_KEY"
```

## 選擇分析指標

`metrics` 為選填欄位，不傳或傳入空陣列時回傳全部支援的指標。範例只請求 `overview`、`risk_type` 和 `risk_address_total`。更多指標和篩選參數見[建立分析任務](/zh-Hant/api-reference/v2/endpoint/analysistaskcreate)。

## 處理錯誤

請求發生錯誤時查看回應中的 `code` 和 `message`，搭配[通用錯誤碼](/zh-Hant/api-reference/common-errors)和[分析錯誤碼](/zh-Hant/api-reference/analysis-errors)定位原因。任務失敗與 HTTP 請求失敗需要分別處理。
