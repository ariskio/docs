## 連接文件 MCP

在已發布的 Arisk 文件頁面中，開啟頁面上下文選單並選擇 **MCP**，複製文件伺服器位址。將它新增至支援遠端 HTTP MCP 的 AI 工具。

文件 MCP 位址是文件站根位址加上 `/mcp`。使用選單提供的位址，保留站點可能包含的路徑前綴。

連接後，讓 AI 搜尋並讀取相關介面頁面，再產生整合程式碼。例如：

```text
請讀取 Arisk 繁體中文 V2 文件，說明如何建立分析任務、查詢狀態並取得結果。
請核對請求必填欄位、任務狀態和回應結構，並附上文件連結。
```

此連接用於搜尋和讀取文件。執行地址分析或修改監控設定需要另外呼叫 Arisk API，並使用您的 API Key。

## 提供 Markdown 內容

如果您的工具不支援 MCP，可使用頁面選單複製 Markdown，或在頁面 URL 後加上 `.md` 取得 Markdown 內容。

文件站根路徑下的 `llms.txt` 提供頁面索引，`llms-full.txt` 提供文件內容。自動產生的索引預設面向站點預設語言和版本；需要其他語言或 V1 時，請同時提供對應頁面連結。

## 產生程式碼前核對

- 明確指定 API 版本與文件語言，避免混用 V1 和 V2 路徑。
- 核對請求網域為 `https://api.arisk.io`，認證請求標頭為 `X-API-Key`。
- 用預留位置代替真實 API Key，在您自己的執行環境中設定金鑰。
- 將產生的欄位和列舉值與介面參考對照。

從[快速開始（V2）](/zh-Hant/quickstart)完成首次整合，或查看[建立分析任務](/zh-Hant/api-reference/v2/endpoint/analysistaskcreate)的完整參數。
