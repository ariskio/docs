This guide uses V2. To maintain a V1 integration, select V1 in the version selector and use its API reference.

## 1. Prepare your API key

Have an API key created in the Arisk console ready, then set it as an environment variable in your terminal. Contact [Arisk support](https://t.me/arisk_cs) if you need help.

```bash
export ARISK_API_KEY="YOUR_API_KEY"
export ARISK_API_BASE="https://api.arisk.io"
```

<Note>
Use your API key on the server. Keep it out of public repositories, frontend code, and prompts sent to AI tools.
</Note>

## 2. Create an analysis task

This request analyzes USDT activity for an Ethereum address. `chain`, `token`, and `address` are required. Replace `address` with the address you want to analyze.

```bash
curl --fail-with-body --request POST "$ARISK_API_BASE/v2/analysis/tasks" \
  --header "X-API-Key: $ARISK_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "chain": "ethereum",
    "token": "usdt",
    "address": "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    "metrics": ["overview", "risk_type", "risk_address_total"]
  }'
```

A successful response includes `task_id`. Save the actual returned value in an environment variable and use the same task ID for subsequent requests.

```bash
export ARISK_TASK_ID="TASK_ID_FROM_RESPONSE"
```

## 3. Check task status

```bash
curl --fail-with-body "$ARISK_API_BASE/v2/analysis/tasks/$ARISK_TASK_ID/status" \
  --header "X-API-Key: $ARISK_API_KEY"
```

Use `status` to decide what to do next. Check again later while the task is pending or processing. If it fails, inspect `message` and stop waiting.

| Value | Status |
| --- | --- |
| `0` | Pending |
| `1` | Processing |
| `2` | Completed |
| `3` | Failed |

## 4. Retrieve analysis results

Retrieve results when `status` is `2`. The response contains a `result` object with the analysis data. See [Get analysis task result](/en/api-reference/v2/endpoint/analysistaskresultget) for the full response schema.

```bash
curl --fail-with-body "$ARISK_API_BASE/v2/analysis/tasks/$ARISK_TASK_ID/result" \
  --header "X-API-Key: $ARISK_API_KEY"
```

## Select analysis metrics

The optional `metrics` field returns all supported metrics when omitted or set to an empty array. This example requests only `overview`, `risk_type`, and `risk_address_total`. See [Create analysis task](/en/api-reference/v2/endpoint/analysistaskcreate) for all metrics and filters.

## Handle errors

For request errors, inspect `code` and `message` in the response and consult [general error codes](/en/api-reference/common-errors) and [analysis error codes](/en/api-reference/analysis-errors). Handle task failures separately from HTTP request failures.
