Use this section to maintain V1 integrations. Follow V1 request paths, parameters, and Webhook payloads.

- After [creating a query](/en/api-reference/v1/endpoint/querycreate), check its [status](/en/api-reference/v1/endpoint/querystatus) and [result](/en/api-reference/v1/endpoint/queryresult).
- Use the [monitored address list](/en/api-reference/v1/endpoint/monitoraddresslist) to inspect records.
- Read the [V1 Webhook overview](/en/api-reference/v1/webhooks/overview) before receiving notifications.

For a new integration, start with the [V2 quickstart](/en/quickstart). V2 examples do not apply to V1 requests.
