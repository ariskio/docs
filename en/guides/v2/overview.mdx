This section covers V2. Use your API Key and choose the workflow for analysis tasks or address monitoring.

## Start integrating

1. Run an analysis task with the [quickstart](/en/quickstart).
2. Follow the [analysis workflow](/en/guides/v2/analysis) to handle status changes and retrieve results.
3. Follow the [monitoring workflow](/en/guides/v2/monitoring) to receive events and manage addresses.

## Supported parameters

V2 analysis tasks and the add-monitor-addresses endpoint accept `ethereum`, `bsc`, and `tron` for `chain`, and `usdt` for `token`. Refer to each endpoint for field details.

For existing V1 integrations, see the [V1 overview](/en/guides/v1/overview). Consult the matching version for request paths and event payloads.
