title: "Read docs with AI"
description: "Give AI tools access to Arisk API documentation through MCP or Markdown."
---

## Connect the documentation MCP

On a published Arisk documentation page, open the page's contextual menu and select **MCP** to copy the documentation server URL. Add it to an AI tool that supports remote HTTP MCP servers.

The documentation MCP URL is your documentation site's base URL followed by `/mcp`. Use the URL supplied by the menu, including any site path prefix.

Once connected, ask the AI to search and read the relevant endpoint pages before generating integration code. For example:

```text
Read the Arisk English V2 documentation and explain how to create an analysis task,
check its status, and retrieve results. Verify required request fields, task statuses,
and response structures. Include links to the documentation.
```

This connection searches and reads documentation. To run address analysis or change monitoring settings, call the Arisk API separately with your API key.

## Provide Markdown content

If your tool does not support MCP, copy Markdown from the page menu or append `.md` to a page URL to retrieve its Markdown content.

The documentation site's `llms.txt` provides a page index, and `llms-full.txt` provides documentation content. Automatically generated indexes default to the site's default language and version. Provide specific page links when you need another language or V1.

## Check generated code

- Specify the API version and documentation language to avoid mixing V1 and V2 paths.
- Verify the API host is `https://api.arisk.io` and the authentication header is `X-API-Key`.
- Use a placeholder instead of your real API key, and set the key in your own runtime environment.
- Compare generated fields and enum values with the API reference.

Follow the [V2 quickstart](/en/quickstart) for your first integration, or see [Create analysis task](/en/api-reference/v2/endpoint/analysistaskcreate) for the full request schema.
